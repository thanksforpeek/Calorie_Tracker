# Calorie Tracker Project Backlog

## Epic 1: Food Diary & Logging Core
- [x] As a user, I want to see a clear list of everything I ate today categorized by meal type (Breakfast, Lunch, Dinner).
- [x] As a user logging a meal, I want to adjust the serving size so the math updates correctly.
- [x] As a user who made a mistake, I want to edit or delete a logged food item from my diary.
- [ ] As a user, I want to create a custom "Recipe" to log a homemade meal easily.
- [x] As a returning user, I want to securely log in with my email or Google account, so that my historical tracking data is saved.
- [x] As a user tracking my food, I want to search a database for a specific food item, so that I can easily find what I ate.
- [ ] As a user, I want to clone an entire meal from yesterday (e.g., copy yesterday's exact breakfast to today), so I can save time on days when I eat the same things.

## Epic 2: Dashboard & Visual Analytics
- [x] As a user, I want to see a main dashboard showing Calories Consumed vs Daily Target.
- [x] As a user, I want three distinct progress bars for Protein, Carbs, and Fats in grams.
- [x] As a user looking at trends, I want to view a bar chart showing my calorie intake for the past 7 days.
- [x] As a user tracking calories, I want to see a "remaining calories" counter that updates in real-time as I log food, so that I don't accidentally overeat.

## Epic 3: User Profiles & Goals
- [x] As a new user, I want to enter my physical metrics (weight, height, age) to estimate my TDEE.
- [x] As an advanced user, I want to manually override targets and set my own custom calorie and macro goals.
- [ ] As a user with a specific fitness goal, I want to choose whether I want to lose fat, maintain weight, or gain muscle, so the app can automatically adjust my calorie targets based on my TDEE.

## Epic 4: Advanced Tracker Features
- [x] As a user who likes dark environments, I want to toggle between a Light Mode and Dark Mode UI, so using the app at night or early in the morning doesn't strain my eyes.
- [ ] As a user who tracks water intake, I want a dedicated quick-tap button to add 250ml or 500ml of water to a daily water counter, so I can stay hydrated.
- [ ] As a busy user, I want to upload a photo of my meal, so that an AI vision model can estimate the food items and their respective portion sizes.
